Boot path (default):

  Narrative / history: doc/linux_compat/BOOT_PATH_EVOLUTION.md
  Open compromises:    doc/linux_compat/BUSYBOX_BOOT_DEFERRALS.md

  Kernel `linux_boot` Path-B spawns /init (symlink → bin/busybox) with
  argv = sh /tests/run_all.sh. Suite is run in user space (pack-generated
  run_one list). Set LINUX_COMPAT_BOOT_BUSYBOX_ONLY=0 for old kernel loop.

Two layers in the tree:

  1. Test PROGRAMS (static ELF64)
     Built by `make user` → copied to rootfs/tests/ + manifest
     Started by /tests/run_all.sh (not by the kernel loop).
     ELFs are packed into rootfs.cpio (see script/config/user.json).

  2. Test DATA FILES (fixtures)
     e.g. ./text.txt, ./mnt/
     Also live under rootfs/ and are read at runtime via VFS.

Layout:

  init                  symlink → bin/busybox (build_busybox.sh; gitignored)
  text.txt              open / read / fstat fixtures
  mnt/                  openat directory tests
  tests/                generated — ELF binaries + manifest (gitignored)
  tests/run_all.sh      generated by pack_user_rootfs.py (explicit run_one)
  tests/boot_smoke.sh   optional quick smoke (from script/rootfs/boot_smoke.sh)
  tests/manifest        one absolute path per line, e.g. /tests/test_echo
  bin/busybox           make user with "busybox": true (default: full applet symlinks)
